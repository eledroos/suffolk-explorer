**Architecture:** A new prep script generates two committed derived assets (`public/data/dtp-lists.json`, `public/downloads/suffolk-dtp-lists.xlsx`) with hard reconciliation gates. `dtpModel.ts`'s content constants change shape (structured detail: paragraphs, fact chips, links); staging/count logic is untouched. `DtpFilterModal.tsx` gains a tab bar (ARIA tablist), share bars, and a lazy-loading Browse tab component. `FilterPanel.tsx`'s DTP entry becomes two lines.

**Tech Stack:** unchanged (React 18 + TS + Vite, vitest); prep script in Python (duckdb + openpyxl, scratch venv).

### Task 1: Prep script and derived assets

**Files:**
- Create: `scripts/prepare_dtp_lists.py`
- Create (generated, committed): `public/data/dtp-lists.json`, `public/downloads/suffolk-dtp-lists.xlsx`
- Test: extend `src/ui/dtpModel.test.ts` is NOT this task; instead the script's own gates are the test (they must run in CI-free fashion: the script exits non-zero on any gate failure).

**Interfaces:**
- Produces `public/data/dtp-lists.json` with EXACTLY this schema (Task 4 consumes it):

```json
{
  "generated": "2026-08-13",
  "source_note": "Derived from a classification worksheet created inside the Suffolk County District Attorney's office in 2020, applied to charge-level records by charge description. This file and the XLSX beside it are derived; the original worksheet is not distributed.",
  "rows": [
    {
      "description": "DRUG, POSSESS CLASS A c94C s34",
      "dtp_class": "YY (decline list)",
      "dtp_review": "Current list",
      "conflict": false,
      "n_2022_2025": 1234,
      "n_2006_2021": 5678
    }
  ]
}
```

  - `dtp_review` is `null` when the string is not in any review section.
  - `conflict` is true exactly when `dtp_class` starts with `YY` and `dtp_review` is `"Proposed, disagreed"`.
  - Rows sorted: class order YY, NY, NS, NN; description A-Z within class.
- Produces `public/downloads/suffolk-dtp-lists.xlsx`: sheets `About`, `All lists`, `Decline list (YY)`, `Presumption against (NY)`, `Case-by-case (NS)`, `Ordinarily prosecuted (NN)`. About sheet: title, four short provenance paragraphs (what the classification is; created inside the DA's office in 2020; applied by charge description; this is a derived file, generated <date>), and the conflict explanation. Data sheets: bold frozen header row, columns Description / Class / Review tier / Charges filed 2022-2025 / Charges filed 2006-2021, column widths 72/22/30/24/24. No other styling.

- [ ] **Step 1: Write the script.** Mirror `../assembled/build_pre2022.py`'s `norm_ws`, `load_dtp`, and `load_review` logic EXACTLY (read that file first; same workbook path constant style as `scripts/prepare_data.py` uses for its inputs). Counts: for each parquet (`public/data/hayden.parquet` filed_in_window, `public/data/history.parquet` filed_in_window), count rows whose `dtp_class` equals the string's class AND whose normalized `charge_description` (or its 75-char prefix) matches the string. Implement the match by building the same string->class map the build used and tagging descriptions, so per-string counts partition the class totals.
- [ ] **Step 2: Reconciliation gates (in-script, exit 1 on failure), printing each:**
  - sum over strings of `n_2022_2025` per class == parquet `SELECT dtp_class, count(*) WHERE filed_in_window GROUP BY 1` (hayden), same for history with `n_2006_2021`. Not-listed rows are NOT in the JSON, so gate compares only the four classes.
  - review-tier distinct-string counts == 46 current / 107 agreed / 16 disagreed-after-precedence.
  - conflict rows == hayden cross-tab count of strings (not charges) tagged YY with review Rejected — verify BOTH: 16 strings, and the charge-level 2,393 recorded in the ground-truth doc still holds.
- [ ] **Step 3: Run it** (scratch venv: `uv venv && uv pip install duckdb openpyxl` under /tmp/dtp-v2). All gates green. Open the XLSX with openpyxl read-back and assert sheet names and header rows programmatically.
- [ ] **Step 4: Append a "dtp-lists reconciliation" section to `docs/specs/dtp-ground-truth-results.md`** with the gate outputs verbatim.
- [ ] **Step 5: Commit** script + both assets + results doc: `git commit -m "DTP lists: derived browse/download assets with reconciliation gates"`
